# Code of Conduct

Purse follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## The short version

- Be kind and assume good intent.
- Critique code and ideas, not people.
- Welcome people who are new, including people new to crypto or AI.
- No harassment, insults, or unwanted personal attention, in any space this
  project uses: issues, pull requests, discussions, or chat.

## If something goes wrong

Contact the maintainer privately through the email on their GitHub profile,
[@thesithunyein](https://github.com/thesithunyein). Reports are kept
confidential.

The maintainer may edit or remove comments, close threads, or block anyone whose
behavior breaks this code, for as long as is needed to keep the project
welcoming.
